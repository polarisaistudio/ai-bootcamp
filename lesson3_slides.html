1 🔗 什么是LangChain

LangChain简介

LangChain是一个用于构建LLM应用的开源框架。它提供了一系列工具和抽象，让开发者能够快速构建复杂的AI应用，而无需从头编写所有代码。

为什么需要LangChain？

❌ 不使用LangChain
  • 需要手动管理API调用
  • 重复编写提示词处理逻辑
  • 难以实现复杂的工作流
  • 缺少标准化的组件
  • 没有内置的记忆管理
✅ 使用LangChain
  • 统一的LLM接口（支持所有主流模型）
  • 可重用的Prompt模板
  • 链式调用轻松组合复杂逻辑
  • 丰富的预构建组件
  • 内置记忆和状态管理

LangChain核心优势

🔌
模型无关

支持OpenAI、Anthropic、Ollama等所有主流LLM

🔗
可组合

像乐高一样组合各种组件构建复杂应用

🚀
快速开发

减少80%的样板代码，专注业务逻辑

🏗️ LangChain核心架构

LangChain由6个核心模块组成，每个模块负责特定功能：

1
Models（模型）

统一的LLM接口，支持GPT、Claude、Ollama等

2
Prompts（提示）

提示模板管理、优化和序列化

3
Chains（链）

将多个组件组合成一个工作流

4
Memory（记忆）

在对话之间保持状态和上下文

5
Agents（代理）

让LLM自主决策使用哪些工具

6
Callbacks（回调）

监控和调试LLM应用

架构示意图
用户输入
   ↓
Prompt Template (格式化输入)
   ↓
LLM Model (生成响应)
   ↓
Output Parser (解析输出)
   ↓
Memory (保存上下文)
   ↓
返回结果

💬 提示模板（Prompt Templates）

为什么需要提示模板？

提示模板让你可以重用和参数化提示词，避免重复编写相似的提示，提高代码的可维护性。

基础示例：简单模板

# prompt_basic.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

# 创建提示模板
template = """你是一个专业的{role}。
请用{language}回答以下问题：

问题：{question}

答案："""

prompt = PromptTemplate(
    template=template,
    input_variables=["role", "language", "question"]
)

# 初始化LLM
llm = OllamaLLM(model="llama3.2")

# 创建链
chain = prompt | llm

# 使用模板
result = chain.invoke({
    "role": "Python教师",
    "language": "中文",
    "question": "什么是装饰器？"
})

print(result)

⛓️ 链式调用（Chains）

链（Chains）是LangChain的核心概念，它允许你将多个组件组合成一个工作流。

简单链：LLMChain

# chain_simple.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

# 创建组件
template = "将以下文本翻译成{target_language}：\n{text}"
prompt = PromptTemplate(
    template=template,
    input_variables=["target_language", "text"]
)

llm = OllamaLLM(model="llama3.2")

# 使用LCEL（LangChain Expression Language）创建链
chain = prompt | llm

# 执行链
result = chain.invoke({
    "target_language": "英语",
    "text": "人工智能正在改变世界"
})

print(result)

顺序链：多步骤处理

# chain_sequential.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

llm = OllamaLLM(model="llama3.2")

# 第一步：生成故事概要
synopsis_template = """为以下主题写一个故事概要：
主题：{topic}
概要："""

synopsis_prompt = PromptTemplate(
    template=synopsis_template,
    input_variables=["topic"]
)

synopsis_chain = synopsis_prompt | llm

# 第二步：基于概要写评论
review_template = """为以下故事概要写一篇评论：
概要：{synopsis}
评论："""

review_prompt = PromptTemplate(
    template=review_template,
    input_variables=["synopsis"]
)

review_chain = review_prompt | llm

# 组合链
full_chain = synopsis_chain | (lambda x: {"synopsis": x}) | review_chain

# 执行
result = full_chain.invoke({"topic": "一个机器人学会了爱"})
print(result)

实战：内容创作流水线

# content_pipeline.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

llm = OllamaLLM(model="llama3.2", temperature=0.8)

# 步骤1：生成标题
title_chain = (
    PromptTemplate.from_template("为以下主题生成一个吸引人的博客标题：{topic}\n标题：")
    | llm
)

# 步骤2：生成大纲
outline_chain = (
    PromptTemplate.from_template("为标题'{title}'生成博客大纲（3-5个要点）：\n大纲：")
    | llm
)

# 步骤3：写文章
article_chain = (
    PromptTemplate.from_template("基于以下大纲写一篇500字的文章：\n{outline}\n文章：")
    | llm
)

# 执行完整流程
def create_blog_post(topic):
    print("🎯 主题:", topic)

    title = title_chain.invoke({"topic": topic})
    print(f"\n📌 标题: {title}\n")

    outline = outline_chain.invoke({"title": title})
    print(f"📋 大纲:\n{outline}\n")

    article = article_chain.invoke({"outline": outline})
    print(f"📝 文章:\n{article}")

# 测试
create_blog_post("人工智能在教育中的应用")

🧠 记忆系统（Memory）

为什么需要记忆？

LLM本身是无状态的，每次调用都是独立的。记忆系统让对话能够保持上下文，实现真正的多轮对话。

记忆类型对比

记忆类型 描述 适用场景
ConversationBufferMemory 保存完整对话历史 短对话，token成本低
ConversationBufferWindowMemory 只保留最近N轮对话 长对话，控制成本
ConversationSummaryMemory 总结历史对话 需要保留语义，节省token

示例1：基础对话记忆

# memory_basic.py
from langchain_ollama import OllamaLLM
from langchain.chains import ConversationChain
from langchain.memory import ConversationBufferMemory

# 初始化
llm = OllamaLLM(model="llama3.2")
memory = ConversationBufferMemory()

# 创建对话链
conversation = ConversationChain(
    llm=llm,
    memory=memory,
    verbose=True  # 显示详细信息
)

# 多轮对话
print(conversation.predict(input="我叫张三，是一名程序员"))
print("\n" + "="*50 + "\n")

print(conversation.predict(input="我喜欢Python编程"))
print("\n" + "="*50 + "\n")

print(conversation.predict(input="我叫什么名字？"))  # 测试记忆
print("\n" + "="*50 + "\n")

# 查看记忆
print("对话历史:")
print(memory.load_memory_variables({}))

示例3：自定义记忆

# memory_custom.py
from langchain_ollama import OllamaLLM
from langchain.memory import ConversationBufferMemory
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.runnables import RunnablePassthrough

llm = OllamaLLM(model="llama3.2")
memory = ConversationBufferMemory(return_messages=True)

# 自定义提示模板
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个友好的AI助手，名字叫小智。"),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{input}")
])

# 创建链
def get_memory(_):
    return memory.load_memory_variables({})["history"]

chain = (
    RunnablePassthrough.assign(history=get_memory)
    | prompt
    | llm
)

# 对话函数
def chat(user_input):
    response = chain.invoke({"input": user_input})

    # 保存到记忆
    memory.save_context(
        {"input": user_input},
        {"output": response}
    )

    return response

# 测试
print(chat("你好！你叫什么名字？"))
print("\n" + "="*50 + "\n")
print(chat("你能帮我做什么？"))
print("\n" + "="*50 + "\n")
print(chat("我刚才问你什么了？"))

3 🎯 实战项目1：智能问答系统

构建一个能够根据不同角色回答问题的智能系统。

# qa_system.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM
from langchain_core.output_parsers import StrOutputParser

class QASystem:
    """智能问答系统"""

    def __init__(self, model="llama3.2"):
        self.llm = OllamaLLM(model=model, temperature=0.7)
        self.parser = StrOutputParser()

        # 不同角色的提示模板
        self.roles = {
            "teacher": """你是一位耐心的教师。
用简单易懂的语言解释：{question}

解释：""",

            "expert": """你是一位技术专家。
用专业术语详细解答：{question}

答案：""",

            "comedian": """你是一位幽默的喜剧演员。
用搞笑的方式回答：{question}

回答："""
        }

    def ask(self, question, role="teacher"):
        """提问"""
        if role not in self.roles:
            return f"错误：角色'{role}'不存在"

        template = self.roles[role]
        prompt = PromptTemplate.from_template(template)

        # 创建链
        chain = prompt | self.llm | self.parser

        # 执行
        return chain.invoke({"question": question})

# 使用示例
if __name__ == "__main__":
    qa = QASystem()

    question = "什么是区块链？"

    print("📚 教师版本:")
    print(qa.ask(question, "teacher"))
    print("\n" + "="*70 + "\n")

    print("🔬 专家版本:")
    print(qa.ask(question, "expert"))
    print("\n" + "="*70 + "\n")

    print("😄 喜剧版本:")
    print(qa.ask(question, "comedian"))

💬 实战项目2：带记忆的聊天机器人

构建一个能记住对话历史的智能聊天机器人。

# chatbot.py
from langchain_ollama import OllamaLLM
from langchain.chains import ConversationChain
from langchain.memory import ConversationBufferWindowMemory
from langchain_core.prompts import PromptTemplate

class SmartChatbot:
    """智能聊天机器人"""

    def __init__(self, name="小智", personality="友好、乐于助人", model="llama3.2"):
        self.name = name
        self.llm = OllamaLLM(model=model, temperature=0.8)

        # 只保留最近5轮对话
        self.memory = ConversationBufferWindowMemory(k=5)

        # 自定义提示模板
        template = f"""你是{name}，一个{personality}的AI助手。

当前对话:
{{history}}
人类: {input}
AI助手:"""

        prompt = PromptTemplate(
            input_variables=["history", "input"],
            template=template
        )

        # 创建对话链
        self.conversation = ConversationChain(
            llm=self.llm,
            memory=self.memory,
            prompt=prompt,
            verbose=False
        )

    def chat(self, user_input):
        """聊天"""
        return self.conversation.predict(input=user_input)

    def reset(self):
        """重置记忆"""
        self.memory.clear()
        return f"{self.name}的记忆已重置"

    def get_history(self):
        """获取对话历史"""
        return self.memory.load_memory_variables({})

# 使用示例
if __name__ == "__main__":
    bot = SmartChatbot(name="小智", personality="友好、幽默")

    print("🤖 小智: 你好！我是小智，有什么可以帮你的吗？")

    # 模拟对话
    conversations = [
        "你好！我叫李明，是一名学生",
        "我正在学习人工智能",
        "你能推荐一些学习资源吗？",
        "我叫什么名字？",  # 测试记忆
        "我在学什么？"  # 测试记忆
    ]

    for user_input in conversations:
        print(f"\n👤 用户: {user_input}")
        response = bot.chat(user_input)
        print(f"🤖 小智: {response}")
        print("-" * 70)

🚀 高级应用：多功能AI助手

综合运用所学知识，构建一个功能丰富的AI助手。

# ai_assistant.py
from langchain_ollama import OllamaLLM
from langchain_core.prompts import PromptTemplate
from langchain.memory import ConversationBufferWindowMemory
from langchain.chains import ConversationChain
import json

class AIAssistant:
    """多功能AI助手"""

    def __init__(self, model="llama3.2"):
        self.llm = OllamaLLM(model=model, temperature=0.7)
        self.memory = ConversationBufferWindowMemory(k=10)

        # 功能列表
        self.features = {
            "translate": self.translate,
            "summarize": self.summarize,
            "code": self.code_helper,
            "chat": self.chat
        }

    def translate(self, text, target_lang="英语"):
        """翻译功能"""
        template = f"将以下文本翻译成{target_lang}：\n{{text}}\n翻译："
        prompt = PromptTemplate.from_template(template)
        chain = prompt | self.llm
        return chain.invoke({"text": text})

    def summarize(self, text):
        """摘要功能"""
        template = """请将以下文本总结成3-5个要点：

文本: {text}

要点:"""
        prompt = PromptTemplate.from_template(template)
        chain = prompt | self.llm
        return chain.invoke({"text": text})

    def code_helper(self, description, language="Python"):
        """代码助手"""
        template = """请用{language}编写代码来实现以下功能：

需求: {description}

代码:"""
        prompt = PromptTemplate.from_template(template)
        chain = prompt | self.llm
        return chain.invoke({"description": description, "language": language})

    def chat(self, user_input):
        """对话功能"""
        template = """你是一个友好的AI助手。

对话历史:
{history}

人类: {input}
助手:"""
        prompt = PromptTemplate(
            template=template,
            input_variables=["history", "input"]
        )

        conversation = ConversationChain(
            llm=self.llm,
            memory=self.memory,
            prompt=prompt
        )

        return conversation.predict(input=user_input)

    def execute(self, command):
        """执行命令"""
        parts = command.split(":", 1)
        if len(parts) != 2:
            return self.chat(command)

        feature, content = parts[0].strip(), parts[1].strip()

        if feature in self.features:
            return self.features[feature](content)
        else:
            return f"未知命令: {feature}。可用命令: {', '.join(self.features.keys())}"

# CLI界面
def main():
    assistant = AIAssistant()

    print("="*70)
    print("🤖 AI多功能助手")
    print("="*70)
    print("\n可用命令:")
    print("  translate: 文本   - 翻译文本")
    print("  summarize: 文本   - 总结文本")
    print("  code: 描述        - 生成代码")
    print("  直接输入          - 聊天对话")
    print("  quit              - 退出\n")
    print("="*70)

    while True:
        user_input = input("\n👤 你: ").strip()

        if user_input.lower() in ['quit', 'exit', '退出']:
            print("\n👋 再见！")
            break

        if not user_input:
            continue

        try:
            response = assistant.execute(user_input)
            print(f"\n🤖 助手: {response}")
        except Exception as e:
            print(f"\n❌ 错误: {e}")

if __name__ == "__main__":
    main()

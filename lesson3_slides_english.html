1 🔗 What is LangChain

LangChain Introduction

LangChain is an open-source framework for building LLM applications. It provides a set of tools and abstractions that enable developers to quickly build complex AI applications without writing all the code from scratch.

Why Do We Need LangChain?

❌ Without LangChain
  • Need to manually manage API calls
  • Repeatedly write prompt processing logic
  • Difficult to implement complex workflows
  • Lack of standardized components
  • No built-in memory management
✅ With LangChain
  • Unified LLM interface (supports all major models)
  • Reusable Prompt templates
  • Easy complex logic with chain composition
  • Rich pre-built components
  • Built-in memory and state management

LangChain Core Advantages

🔌
Model Agnostic

Supports OpenAI, Anthropic, Ollama and all major LLMs

🔗
Composable

Build complex apps like LEGO with various components

🚀
Rapid Development

Reduce 80% boilerplate code, focus on business logic

🏗️ LangChain Core Architecture

LangChain consists of 6 core modules, each responsible for specific functions:

1
Models

Unified LLM interface, supports GPT, Claude, Ollama, etc.

2
Prompts

Prompt template management, optimization and serialization

3
Chains

Combine multiple components into a workflow

4
Memory

Maintain state and context between conversations

5
Agents

Let LLM autonomously decide which tools to use

6
Callbacks

Monitor and debug LLM applications

Architecture Diagram
User Input
   ↓
Prompt Template (format input)
   ↓
LLM Model (generate response)
   ↓
Output Parser (parse output)
   ↓
Memory (save context)
   ↓
Return Result

💬 Prompt Templates

Why Prompt Templates?

Prompt templates allow you to reuse and parameterize prompts, avoiding duplicate code and improving maintainability.

Basic Example: Simple Template

# prompt_basic.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

# Create prompt template
template = """You are a professional {role}.
Please answer the following question in {language}:

Question: {question}

Answer:"""

prompt = PromptTemplate(
    template=template,
    input_variables=["role", "language", "question"]
)

# Initialize LLM
llm = OllamaLLM(model="llama3.2")

# Create chain
chain = prompt | llm

# Use template
result = chain.invoke({
    "role": "Python teacher",
    "language": "English",
    "question": "What are decorators?"
})

print(result)

Practical Template: Few-shot Learning

# prompt_fewshot.py
from langchain_core.prompts import FewShotPromptTemplate, PromptTemplate
from langchain_ollama import OllamaLLM

# Prepare examples
examples = [
    {"input": "happy", "output": "sad"},
    {"input": "tall", "output": "short"},
    {"input": "day", "output": "night"},
]

# Example format template
example_template = """
Input: {input}
Output: {output}
"""

example_prompt = PromptTemplate(
    input_variables=["input", "output"],
    template=example_template
)

# Few-shot template
few_shot_prompt = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    prefix="Find the antonym of the following word:",
    suffix="Input: {word}\nOutput:",
    input_variables=["word"]
)

llm = OllamaLLM(model="llama3.2")
chain = few_shot_prompt | llm

# Test
result = chain.invoke({"word": "smart"})
print(f"Antonym of smart: {result}")

⛓️ Chains

Chains are a core concept in LangChain, allowing you to combine multiple components into a workflow.

Simple Chain: LLMChain

# chain_simple.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

# Create components
template = "Translate the following text to {target_language}:\n{text}"
prompt = PromptTemplate(
    template=template,
    input_variables=["target_language", "text"]
)

llm = OllamaLLM(model="llama3.2")

# Create chain using LCEL (LangChain Expression Language)
chain = prompt | llm

# Execute chain
result = chain.invoke({
    "target_language": "Spanish",
    "text": "Artificial intelligence is changing the world"
})

print(result)

Sequential Chain: Multi-step Processing

# chain_sequential.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

llm = OllamaLLM(model="llama3.2")

# Step 1: Generate story synopsis
synopsis_template = """Write a story synopsis for the following topic:
Topic: {topic}
Synopsis:"""

synopsis_prompt = PromptTemplate(
    template=synopsis_template,
    input_variables=["topic"]
)

synopsis_chain = synopsis_prompt | llm

# Step 2: Write review based on synopsis
review_template = """Write a review for the following story synopsis:
Synopsis: {synopsis}
Review:"""

review_prompt = PromptTemplate(
    template=review_template,
    input_variables=["synopsis"]
)

review_chain = review_prompt | llm

# Combine chains
full_chain = synopsis_chain | (lambda x: {"synopsis": x}) | review_chain

# Execute
result = full_chain.invoke({"topic": "a robot that learned to love"})
print(result)

Practical Example: Content Creation Pipeline

# content_pipeline.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM

llm = OllamaLLM(model="llama3.2", temperature=0.8)

# Step 1: Generate title
title_chain = (
    PromptTemplate.from_template("Generate an engaging blog title for this topic: {topic}\nTitle:")
    | llm
)

# Step 2: Generate outline
outline_chain = (
    PromptTemplate.from_template("Generate a blog outline (3-5 points) for the title '{title}':\nOutline:")
    | llm
)

# Step 3: Write article
article_chain = (
    PromptTemplate.from_template("Write a 500-word article based on this outline:\n{outline}\nArticle:")
    | llm
)

# Execute full workflow
def create_blog_post(topic):
    print("🎯 Topic:", topic)

    title = title_chain.invoke({"topic": topic})
    print(f"\n📌 Title: {title}\n")

    outline = outline_chain.invoke({"title": title})
    print(f"📋 Outline:\n{outline}\n")

    article = article_chain.invoke({"outline": outline})
    print(f"📝 Article:\n{article}")

# Test
create_blog_post("Applications of AI in Education")

🧠 Memory Systems

Why Memory?

LLMs are stateless by nature - each call is independent. Memory systems allow conversations to maintain context, enabling true multi-turn dialogues.

Memory Types Comparison

Memory Type Description Use Cases
ConversationBufferMemory Stores full conversation history Short conversations, low token cost
ConversationBufferWindowMemory Only keeps last N conversation turns Long conversations, cost control
ConversationSummaryMemory Summarizes conversation history Preserve semantics, save tokens

Example 1: Basic Conversation Memory

# memory_basic.py
from langchain_ollama import OllamaLLM
from langchain.chains import ConversationChain
from langchain.memory import ConversationBufferMemory

# Initialize
llm = OllamaLLM(model="llama3.2")
memory = ConversationBufferMemory()

# Create conversation chain
conversation = ConversationChain(
    llm=llm,
    memory=memory,
    verbose=True  # Show detailed information
)

# Multi-turn conversation
print(conversation.predict(input="My name is John and I'm a programmer"))
print("\n" + "="*50 + "\n")

print(conversation.predict(input="I love Python programming"))
print("\n" + "="*50 + "\n")

print(conversation.predict(input="What's my name?"))  # Test memory
print("\n" + "="*50 + "\n")

# View memory
print("Conversation history:")
print(memory.load_memory_variables({}))

Example 3: Custom Memory

# memory_custom.py
from langchain_ollama import OllamaLLM
from langchain.memory import ConversationBufferMemory
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.runnables import RunnablePassthrough

llm = OllamaLLM(model="llama3.2")
memory = ConversationBufferMemory(return_messages=True)

# Custom prompt template
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a friendly AI assistant named Smarty."),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{input}")
])

# Create chain
def get_memory(_):
    return memory.load_memory_variables({})["history"]

chain = (
    RunnablePassthrough.assign(history=get_memory)
    | prompt
    | llm
)

# Chat function
def chat(user_input):
    response = chain.invoke({"input": user_input})

    # Save to memory
    memory.save_context(
        {"input": user_input},
        {"output": response}
    )

    return response

# Test
print(chat("Hello! What's your name?"))
print("\n" + "="*50 + "\n")
print(chat("What can you help me with?"))
print("\n" + "="*50 + "\n")
print(chat("What did I just ask you?"))

3 🎯 Project 1: Smart Q&A System

Build an intelligent system that can answer questions with different personas.

# qa_system.py
from langchain_core.prompts import PromptTemplate
from langchain_ollama import OllamaLLM
from langchain_core.output_parsers import StrOutputParser

class QASystem:
    """Smart Q&A System"""

    def __init__(self, model="llama3.2"):
        self.llm = OllamaLLM(model=model, temperature=0.7)
        self.parser = StrOutputParser()

        # Different role prompt templates
        self.roles = {
            "teacher": """You are a patient teacher.
Explain in simple terms: {question}

Explanation:""",

            "expert": """You are a technical expert.
Provide a detailed answer using technical terminology: {question}

Answer:""",

            "comedian": """You are a humorous comedian.
Answer in a funny way: {question}

Answer:"""
        }

    def ask(self, question, role="teacher"):
        """Ask a question"""
        if role not in self.roles:
            return f"Error: Role '{role}' doesn't exist"

        template = self.roles[role]
        prompt = PromptTemplate.from_template(template)

        # Create chain
        chain = prompt | self.llm | self.parser

        # Execute
        return chain.invoke({"question": question})

# Usage example
if __name__ == "__main__":
    qa = QASystem()

    question = "What is blockchain?"

    print("📚 Teacher version:")
    print(qa.ask(question, "teacher"))
    print("\n" + "="*70 + "\n")

    print("🔬 Expert version:")
    print(qa.ask(question, "expert"))
    print("\n" + "="*70 + "\n")

    print("😄 Comedian version:")
    print(qa.ask(question, "comedian"))

💬 Project 2: Chatbot with Memory

Build an intelligent chatbot that remembers conversation history.

# chatbot.py
from langchain_ollama import OllamaLLM
from langchain.chains import ConversationChain
from langchain.memory import ConversationBufferWindowMemory
from langchain_core.prompts import PromptTemplate

class SmartChatbot:
    """Smart Chatbot"""

    def __init__(self, name="Smarty", personality="friendly and helpful", model="llama3.2"):
        self.name = name
        self.llm = OllamaLLM(model=model, temperature=0.8)

        # Keep only last 5 conversation turns
        self.memory = ConversationBufferWindowMemory(k=5)

        # Custom prompt template
        template = f"""You are {name}, a {personality} AI assistant.

Current conversation:
{{history}}
Human: {{input}}
AI Assistant:"""

        prompt = PromptTemplate(
            input_variables=["history", "input"],
            template=template
        )

        # Create conversation chain
        self.conversation = ConversationChain(
            llm=self.llm,
            memory=self.memory,
            prompt=prompt,
            verbose=False
        )

    def chat(self, user_input):
        """Chat"""
        return self.conversation.predict(input=user_input)

    def reset(self):
        """Reset memory"""
        self.memory.clear()
        return f"{self.name}'s memory has been reset"

    def get_history(self):
        """Get conversation history"""
        return self.memory.load_memory_variables({})

# Usage example
if __name__ == "__main__":
    bot = SmartChatbot(name="Smarty", personality="friendly and humorous")

    print("🤖 Smarty: Hello! I'm Smarty, how can I help you?")

    # Simulate conversation
    conversations = [
        "Hi! My name is Alex and I'm a student",
        "I'm studying artificial intelligence",
        "Can you recommend some learning resources?",
        "What's my name?",  # Test memory
        "What am I studying?"  # Test memory
    ]

    for user_input in conversations:
        print(f"\n👤 User: {user_input}")
        response = bot.chat(user_input)
        print(f"🤖 Smarty: {response}")
        print("-" * 70)

🚀 Advanced Application: Multi-function AI Assistant

Combine everything you've learned to build a feature-rich AI assistant.

# ai_assistant.py
from langchain_ollama import OllamaLLM
from langchain_core.prompts import PromptTemplate
from langchain.memory import ConversationBufferWindowMemory
from langchain.chains import ConversationChain
import json

class AIAssistant:
    """Multi-function AI Assistant"""

    def __init__(self, model="llama3.2"):
        self.llm = OllamaLLM(model=model, temperature=0.7)
        self.memory = ConversationBufferWindowMemory(k=10)

        # Feature list
        self.features = {
            "translate": self.translate,
            "summarize": self.summarize,
            "code": self.code_helper,
            "chat": self.chat
        }

    def translate(self, text, target_lang="Spanish"):
        """Translation feature"""
        template = f"Translate the following text to {target_lang}:\n{{text}}\nTranslation:"
        prompt = PromptTemplate.from_template(template)
        chain = prompt | self.llm
        return chain.invoke({"text": text})

    def summarize(self, text):
        """Summary feature"""
        template = """Please summarize the following text into 3-5 key points:

Text: {text}

Key points:"""
        prompt = PromptTemplate.from_template(template)
        chain = prompt | self.llm
        return chain.invoke({"text": text})

    def code_helper(self, description, language="Python"):
        """Code helper"""
        template = """Write {language} code to implement the following:

Requirements: {description}

Code:"""
        prompt = PromptTemplate.from_template(template)
        chain = prompt | self.llm
        return chain.invoke({"description": description, "language": language})

    def chat(self, user_input):
        """Chat feature"""
        template = """You are a friendly AI assistant.

Conversation history:
{history}
Human: {input}
Assistant:"""
        prompt = PromptTemplate(
            template=template,
            input_variables=["history", "input"]
        )

        conversation = ConversationChain(
            llm=self.llm,
            memory=self.memory,
            prompt=prompt
        )

        return conversation.predict(input=user_input)

    def execute(self, command):
        """Execute command"""
        parts = command.split(":", 1)
        if len(parts) != 2:
            return self.chat(command)

        feature, content = parts[0].strip(), parts[1].strip()

        if feature in self.features:
            return self.features[feature](content)
        else:
            return f"Unknown command: {feature}. Available commands: {', '.join(self.features.keys())}"

# CLI interface
def main():
    assistant = AIAssistant()

    print("="*70)
    print("🤖 Multi-function AI Assistant")
    print("="*70)
    print("\nAvailable commands:")
    print("  translate: text   - Translate text")
    print("  summarize: text   - Summarize text")
    print("  code: description - Generate code")
    print("  direct input      - Chat conversation")
    print("  quit              - Exit\n")
    print("="*70)

    while True:
        user_input = input("\n👤 You: ").strip()

        if user_input.lower() in ['quit', 'exit']:
            print("\n👋 Goodbye!")
            break

        if not user_input:
            continue

        try:
            response = assistant.execute(user_input)
            print(f"\n🤖 Assistant: {response}")
        except Exception as e:
            print(f"\n❌ Error: {e}")

if __name__ == "__main__":
    main()
